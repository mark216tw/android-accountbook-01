# 產品規格

## 產品定位

「簡單記帳單機版」是一款不需要帳號、網路或同步服務的個人記帳 App。MVP 的核心目標是讓使用者在開啟 App 後，以最少操作完成一筆記帳，並立即了解本月剩餘可用預算。

## 目標使用者

- 想快速記錄日常收支的使用者
- 不需要複雜會計科目或多帳本的人
- 重視資料留在本機與不需登入的人

## MVP 功能

### 快速記帳

1. 開啟 App。
2. 選擇支出或收入。
3. 使用畫面內建數字鍵盤輸入新台幣整數金額。
4. 選擇日期與分類，必要時展開備註欄。
5. 儲存帳目。

輸入金額必須大於零，且必須選擇有效分類。備註選填且最多 100 個字元。日期預設為當天，可補記過去或未來帳目。寫入成功後才清空輸入內容，收入與支出分別記住最近使用的分類。

### 預設分類

支出分類：餐飲、購物、居住、交通、娛樂、醫療、教育、其他。

收入分類：薪資、獎金、投資、兼職、禮金、其他。

使用者可新增、改名、調整順序、停用或刪除分類。已被帳目使用的分類不會實際刪除，而是轉為停用，以保留歷史資料完整性。

### 歷史流水帳

- 帳目按日期由新到舊排列
- 以日期群組並顯示每日收入與支出總額
- 搜尋分類名稱、備註或金額
- 依全部／支出／收入及當月歷史分類篩選
- 點擊帳目可修改收支類型、金額、日期、分類或備註
- 刪除帳目後可透過 Snackbar 復原

### CSV 匯出

- 從流水帳匯出選定月份的全部帳目，不受畫面搜尋及篩選影響
- 使用 UTF-8 BOM、CRLF 與完整雙引號欄位，方便 Windows Excel 開啟
- 文字欄位會防止試算表公式注入
- CSV 用於試算表分析，不作為可還原備份

### 月預算

可切換任意過去或未來月份。每個月份分別保存預算，並顯示收入、支出與收支結餘。預算只計算支出，不以收入抵銷支出。

```text
剩餘額度 = 本月預算 - 本月總支出
```

警示規則：

| 使用比例 | 狀態 | 顏色 |
| --- | --- | --- |
| 低於 60% | 安全 | 綠色 |
| 60% 至低於 80% | 警告 | 黃色 |
| 80% 以上 | 危險／超支 | 紅色 |

超過預算時，進度條維持全滿並顯示超支金額。

### 支出摘要

首頁以甜甜圈圖顯示選定月份支出金額最高的五個分類、其餘分類合計、各分類金額及占該月總支出的比例。無支出時顯示空狀態。

### 備份與還原

- 使用 Android 系統檔案選擇器，不要求儲存空間權限
- JSON 備份包含分類、帳目與每月預算
- 還原前完整驗證格式、關聯與資料範圍
- 還原會以單一資料庫 transaction 完整取代現有帳務資料
- 檔案大小上限為 10 MB
- 顯示模式與主題色屬於裝置偏好，不包含在帳務備份

### 外觀設定

- 顯示模式：系統、淺色、深色，預設跟隨系統
- 預設色彩：活力紫、珊瑚橘、天空藍、薄荷綠、檸檬黃、莓果粉
- 自訂色彩：單一 Hue 滑桿與即時顏色預覽
- 主題或顯示模式變更後立即套用
- 狀態列與系統 Navigation Bar 跟隨目前明暗模式
- 系統返回鍵從設定頁返回主畫面

## 非 MVP 範圍

- 使用者帳號、雲端同步或多人共用
- 多幣別與小數金額
- 收據照片、OCR 或電子發票整合
- 定期帳目與通知
- CSV 匯入
- 跨月趨勢

## 隱私

App 不要求網路權限，帳目、分類與預算保存在 Room 本機資料庫，外觀偏好保存在 DataStore。App 已關閉 Android 自動雲端備份；卸載 App 或清除應用程式資料會移除所有資料，需要保存時請手動匯出 JSON。
